# Sunder

## How to play

1. Download **[SunderLauncher.exe](https://github.com/Soomakee/sunder-launcher/releases/latest/download/SunderLauncher.exe)**.
2. Put it in its own folder, like `Documents\Sunder`.
3. Double-click it. It downloads the game and starts it.

If Windows says "Windows protected your PC", click **More info**, then **Run anyway**.

Always open Sunder with the launcher. It updates the game for you automatically.
